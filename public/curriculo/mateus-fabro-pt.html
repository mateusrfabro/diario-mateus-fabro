Analista de Dados — frente de dados de 2 operações

Squad de dados de quatro pessoas para três operações de iGaming (Brasil/BRL, Paquistão/PKR, Colômbia/COP). Lidero a frente de dados das duas mais novas: pipelines, migração de data lake, antifraude, tracker de atribuição e painéis.

Engenharia de dados e plataforma

  • Liderei a camada de consumo da migração do data lake (Athena legado → S3 Tables/Iceberg, 234 tabelas, 3,07 bi de registros): camada de conexão bi-ambiente com fonte única e rollback por uma variável de ambiente, sem quebrar os pipelines consumidores.
  • Fiz o retrofit multi-tenant do analytics (duas operações nas mesmas tabelas): registry tipado de tenants, escopo obrigatório no runner de queries e linter fail-closed com allowlist-ratchet (43 → 3 exceções) e hook no editor — nascido de um incidente real de escopo de moeda.
  • Construí a camada gold de torneios, juntando três fontes (PostgreSQL, MongoDB Atlas, postgres_fdw) num contrato só, fail-closed: fonte fora do ar vira estado UNREACHABLE, nunca zero falso.
  • Padronizei o deploy git-first em EC2 (AWS SSM, smoke test remoto, timers systemd).
  • Otimizei a consulta crítica de 240 s (timeout) para 21 s, com equivalência provada por conjunto.

Sistemas e aplicações

  • Evoluí e operei o tracker de atribuição multi-tenant (NestJS 11 + Next.js 15): postbacks de conversão, despacho para as APIs de conversão dos canais e junção de custo com receita → CAC, ROAS e LTV por campanha e criativo.
  • Entreguei do zero o módulo de administração e autenticação (sessões opacas com hash de token, guards, audit log) e toda a camada de custo de mídia — Meta Graph API multi-BM, Google Ads e TikTok, 6 cron jobs — substituindo um fornecedor pago.
  • Dashboards e serviços web em produção: Flask (Central de Bônus, CRM), Dash/Plotly com Docker, FastAPI e uma malha de alertas operacionais em WhatsApp (Evolution API self-hosted), Slack e Telegram com alarme de silêncio por frescor de dado (dead-man's switch).

Antifraude e ML

  • Construí o serviço diário de risco da operação do Paquistão: 5 detectores (cluster de carteira, bônus → saque, anel de indicação, burst de e-mail, retenção de saque), delta contra snapshot e digest HTML + Telegram.
  • Construí o PCR — score de crédito de jogador em tiers com janela rolling de 90 dias, publicado de forma atômica no CRM preservando as tags de risco.
  • Inferência de gênero por primeiro nome com dicionário treinado na própria base: 99,45% de acurácia em holdout 70/30, funil auditável a partir da base inteira (1,38 M jogadores).

IA aplicada

  • Montei um squad de 25 agentes Claude Code com papel definido (10 do squad de dados + 15 gerais) e 5 skills próprias (escopo de tenant, multimoeda, promoção de memória, PRD e fábrica de páginas), com gate obrigatório (extração → boas práticas → auditoria → entrega) e hooks que bloqueiam git destrutivo e commit sem teste.
  • Mantenho memória em três camadas (projeto → global → export): 125 lições registradas, cada uma com origem, motivo e forma de aplicar, e um script que prova que o índice não esqueceu nenhuma.
  • API da Anthropic em produção em dois produtos (IA multimodal no DumpAI; chatbot clínico no Nous Clinical), agente LangChain/n8n na secretária de WhatsApp e laboratório local (Ollama + PyTorch numa RTX 4060) para saber o que roda sem API.
